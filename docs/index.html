Biomix Tutorial

Biomix is the University of Delaware's High Performance Computing (HPC) cluster for life sciences research. This walk-through will guide you through the the basics of using Biomix for your computational needs.

This walkthrough does not assume any prior knowledge of using computing clusters. However, it does assume that you have some knowledge of the the command line. If you are unfamiliar with the command line and Bash, you will need to complete an extra tutorial/boot camp (linked below).

In addition to this tutorial, Biomix has documentation that can be found here, which will be referenced and linked over the course of this walkthrough. If you are already familiar with the Linux command line, the documentation may be all you need to get started. However, the tutorial aims to provide additional context and explanation of concepts in beginner-friendly terms.

Why use Biomix?

Biomix allows Delaware life science researchers to perform analyses that may be impossible or impractical on PCs. To get an idea of what other researchers are using Biomix for, checkout this list of software that comes pre-installed on Biomix.
