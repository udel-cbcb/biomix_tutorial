# Biomix Tutorial

This repository contains the material for a tutorial that teaches newcomers to high-performance computing how to use [Biomix](https://bioinformatics.udel.edu/core/hpc/), an HPC cluster for life sciences research hosted at the University of Delaware and supported by Delaware INBRE and the Delaware Biotechnology institute.  

Please see our [acknowledgement statement](https://bioinformatics.udel.edu/core/acknowledgement/) and recognize these important contributions in any publications or other products resulting from their use, as appropriate.
